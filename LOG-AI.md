# Log Penggunaan AI — Proyek Pemrograman Web 1

Catatan penggunaan alat bantu AI selama pengerjaan praktikum Modul 2 hingga Modul 4 sesuai ketentuan tingkat AI Hijau.

## Modul 2 — Tata Letak Responsif dan CSS
- **Alat AI:** Gemini
- **Tujuan:** Menanyakan cara mengatur tata letak kartu produk menggunakan CSS Grid (uto-fit dan minmax) agar rapi di layar ponsel maupun laptop.
- **Tindakan Mandiri:** Menyesuaikan palet warna, ukuran huruf, jarak antar-elemen, serta mengisi sendiri konten profil toko dan tabel jam buka galeri.

## Modul 3 — Interaktivitas JavaScript dan Validasi Formulir
- **Alat AI:** Gemini
- **Tujuan:** Memeriksa penyebab galat pada logika filter kategori dan pencocokan kata kunci pencarian, serta merapikan format pesan ringkasan WhatsApp pada js/form.js.
- **Tindakan Mandiri:** Menyusun 16 data produk Sasirangan beserta gambar dan deskripsinya, menguji seluruh validasi input formulir secara manual, serta memperbaiki pesan kesalahan agar mudah dipahami pengguna.

## Modul 4 — Fetch API, API Jadwal Salat, dan Audit Mutu
- **Alat AI:** Gemini
- **Tujuan:** Membantu mengubah format array katalog ke struktur JSON sah (data/katalog.json) serta meninjau struktur fungsi sync/await dan 	ry/catch pada muatKatalog() dan muatJadwalSalat().
- **Tindakan Mandiri:** Menguji empat keadaan data (memuat, berhasil, kosong, gagal) lewat Live Server dan DevTools Network, menambahkan favicon, merapikan README.md, serta melakukan audit Lighthouse di GitHub Pages.
